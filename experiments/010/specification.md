# Experiment 010: survival-to-action

Preregistered before implementation, 2026-10-08, baseline `cf82e30`.

Question: can bounded retained differences propagate through voluntary inquiry
among competing concerns into executed resource actions and persistent consequences?
This tests agency under bounded information, not optimal memory or human likeness.

Competing explanations: A retained differences are inert; B they change inquiry;
C changed inquiry leaves executed behavior unchanged; D the complete chain changes
persistent state; E apparent effects depend on future-aware or scripted targeting.
All are live possibilities. We will retain failures and mistakes.

Chain: actual refusals create two own unresolved concerns; matched deliveries
compete at capacity32; a fixed public meeting permits one inquiry per actor before
a fixed resource encounter; the existing mechanism chooses concern/source/method
or Pause; legitimate replies revise local state; the existing resource policy
executes actions; a later consumption operation tests persistent inventory effects.
Initial state and all pre-choice evidence/opportunities match across modes. No
resource or profile reset follows the first voluntary inquiry divergence.

Reuse005 concern creation/status/importance and replacement trust contributions,
006 candidate enumeration, priors55/65, learned estimates, novelty, costs10/28 and
public offers,007 local independence and voluntary response channels,008 Grouped
assessment and009 unchanged FIFO/Quality/Salient at32. No retention retuning.

006 already compares multiple concerns. It lacks current assessment-basis input.
We will compare the unchanged inquiry path with an explicitly opt-in adapter:
for each active own concern compute Grouped support from the current own retained
basis; `need = 100 - abs(support)`; multiply the existing candidate benefit by
need/100 (integer truncation), subtract the existing cost, and preserve candidate
order/tie rules. Pause remains zero. This heuristic discounts currently answered
questions; it is not calibrated information theory. No new planner or selector.
Projection is at most8 (concern,event,support) triples, derived from at most32
local items. No roots, observer records, partner inventory, scenario, seed, truth
or future usefulness reach the adapter. Cached concern state survives eviction;
the projection does not reopen resolved concerns or erase legacy consequences.
Both unchanged and projected paths are evaluated; a projection-dependent result
does not establish an effect in the unmodified006 mechanism.

Controlled families (same schedules across retention modes): protected weak concern;
late minor item useful to FIFO; unequal importance/uncertain later relevance;

## Construction and audit review

The first construction pass did not make the minor item low enough relative to
Salient's unchanged importance bonus, and did not establish the all-forget control.
Those coverage omissions were corrected to goal40/quality20 and distinct90 traffic
before interpreting the preview. Hidden-root fixture readings were made inverted
to exercise the promised mistaken-confidence case. No retention/inquiry weights,
thresholds or resource traits were changed. The already planned mirrored resource
partners include both helpful and costly allocations. This is a disclosed fixture
construction review, not a claim of a blind untouched preregistration.

After preview, add read-only diagnostics at before-inquiry, after-inquiry and
after-later-delivery using the identical future resource observation. These never
enter runtime policies or select targets. A conservative complete-chain comparison
requires matching pre-inquiry action readiness, differing immediate post-inquiry
readiness, and agreement with actual executed opening actions. This prevents
counting mere coincident inquiry/action differences caused by redelivery before
inquiry or a later independent correction. Probes supplement actual execution.

The resource encounter may itself offer later automatic inquiry under006. It is
kept in all modes, after the executed decision; no mode is reset or blocked from
this legitimate opportunity. The limit is one inquiry before the consequential
resource decision. A later revision cannot retroactively transfer missed food.

Causal review found that revealing only one of two Unknown origins cannot legally
establish their shared lineage. The late-attribution fixture now delivers both
providers' actual available attribution after the first slot, in every mode.
This corrects coverage without changing either policy. Hidden/later-attribution
cases remain excluded from conservative full-chain counts because an independent
post-inquiry delivery also affects state; their observed effects are reported.
