## Exact primary intervention

For every available ordinary actor, first construct the existing legal four
candidates and masks, including live outgoing invitation exclusion. Preserve
eligibility, inner selected contact/source/method and candidate order.

- **Baseline:** each final score equals its original candidate score.
- **MealRelief:** an eligible Consume receives bonus min(H,40); its final score is
  H+min(H,40). Ineligible Consume stays-1. All other bonuses are zero and all other
  scores remain original. H is current own modeled hunger,0–100.40 is the unchanged
  meal effect, not a fitted weight. No retuning or alternative threshold sweep.
- Select the first strict maximum in order Wait,Consume,Invite,Acquire. Preserve
  original contact candidate tie order. Integer addition/min is exact; no float,
  rounded expected value, learned policy weight or actual future duration.

This is a heuristic translation of current locally known physical relief into the
existing score scale, not calibrated utility. It can double-count need relative to
inherited scores; that limitation is part of evaluation. It can leave contact ahead
of consumption. No rule forces survival or a meal. Resource-response/negotiation
scores and inquiry learning are unchanged. New audit terms do not become cognition.

This intervention changes ordinary choices only. Incoming reply/admission work can
reserve an actor before ordinary selection; unchanged recipient acceptance can
therefore still displace meals. Count such blocked time separately from an eligible
meal losing on score. This does not test a new valuation rule for recipient consent.

## Competing hypotheses

H0: scores differ but choices/execution remain identical.
H1: current meal relief changes voluntary consumption/contact choices.
H2: changed choices alter real food/need/social or information consequences.
H3: more meals coexist with lost useful contact or unequal/worse outcomes.
H4: contact still dominates some food-owned high-hunger choices.
H5: behavior changes temporarily then reconverges materially, with persistent social
history or need differences. H6: fixed scarcity ultimately dominates both policies.
H7: changes mainly reflect arbitrary scale sensitivity, not a broadly useful rule.
H8: added audit/maintenance exceeds useful explanatory distinction. All are valid.
