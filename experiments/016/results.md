## Question, hypotheses and treatment boundary

Can own legitimately observed invitation outcomes adapt later contact,reducing
some repeated failures while preserving consent,uncertain availability and costly
avoidance? Compare sufficient existing cognition,missing feedback,bounded adaptation,
simpler transient feedback,harmful outdated avoidance,scheduling/scoring artifacts,
and outcome-specific distinctions. No long-term willingness estimate was assumed.

Existing015 state does not retain invitation outcomes. New `contact_learning.rs`
adds a finite retry record,not a partner-reliability oracle. New isolated ECS adapter
reuses old input construction,preparation,legality,matching,resource/inquiry resolution
and consumption. Frozen015 implementation files remain byte-identical; the prospective
adapter copies its private wave/resolver routines rather than refactoring protected
source. Old runtime/default paths receive only module declarations.

Insertion FIFO; existing-key update stays in place. Expire until<=now at decision

Wait0 can end the period. Successful resource contact does not erase an inquiry-type
failure. No query event content,private motive,truth,future response or objective
provenance enters a cell. Existing cognitive capacities/lifetimes stay unchanged.

Recipient control changes only Continue to0,so incoming positive own readiness or

still survives incoming acceptance. This control is a prospective protocol factor,
not a repair/default or optimal response. **Unchanged versus Control is not a learning
effect.** Control versus each learner holds recipient formula and arbitration fixed;
feedback can legitimately alter incoming options later. Pure choose/update functions
are replaceable; actor input contains only own bounded feedback and old own observation.

## What the actor actually receives

After response/arbitration and actual wave execution,the resolver projects one own
outgoing result: Declined(no consent),AcceptedUnmet(consent but no meeting),Met,
Expired(own deadline),or Unavailable(current public status). It exposes neither precise
Contention disposition nor competing edge/other person's score/private reason. Declined
does not establish intentional personal rejection: recipient may prefer Continue or
an unobserved invitation. Incoming-only/Wait actors receive no invented outgoing signal.

Projection is trusted resolution,not a policy reading observer history. The pure
learning function receives only its owner's signal/cells. Complete history/audit
never restores an expired/evicted cell. Failure alone never creates resource Refuse,
episode,trust,receipt,006 novelty or012 progress. Met can yield actual resource Refuse,
silence,redundant report or misleading change. These stages remain distinct.

No Unavailable/Expired feedback occurs in the primary matrix: legal admission avoids
those invitations. Current prior commitments instead remove candidates. Dedicated
projection/update boundary tests cover these signals without inventing observed
rejections. AcceptedUnmet is common and is not trained as personal refusal.

## Scientific classification and conclusion

Demonstrated: own legitimately delivered contact feedback survives finitely,changes
later voluntary choices and sometimes executed/persistent outcomes. Mistaken avoidance,
actual failed negotiation and narrow simpler-control benefit are causally observed.
Existing cognition alone cannot reproduce a retained contact result that it never
stored,but can equal or outperform the new mechanism on meaningful outcomes.

Mechanism-dependent:6/12/2-tick thresholds,two versus one record,insertion FIFO/overwrite,
contact-type separation,provisional consent,Continue0 control,three-person room,
conservative reservations,all-Wait termination and stable ID order. This is retry
allocation,not calibrated learning of willingness. No long-term estimate/map is justified.

Ambiguous: how much benefit comes from contact avoidance versus altered arbitration,
extra adverse relationship experience or resource redistribution;minimal necessary
state;preferred tradeoffs between contact types and meal timing;ecological prevalence.
The recipient control isolates learning comparisons but is not itself justified for
adoption. Discrete boundary-sampled circumstances limit continuous-time interpretation.

Unsupported: optimal frequency,truth/welfare ranking,mind reading,human motives,
psychological realism,friendship,groups/institutions,autonomous travel/production,
intelligence,planner or civilization. Mistakes were not tuned away. No016 protection.

The strongest open question is whether a minimal feedback rule can distinguish
unproductive retry from an opportunity worth reconsidering under changing circumstances,
without relying on arbitrary cooldown/overwrite timing or scheduling artifacts. The
present two-cell Typed rule does not demonstrate enough additional useful behavior
to justify adoption. The one-record control's narrow gains warrant preservation,
not promotion. A negative hypothesis can still yield a defensible completed experiment.
