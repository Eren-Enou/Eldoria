# Experiment027 — learning from lived material consequences

Prospective registration; research, unadopted. Protected endpoint remains001–026.
Headless only. No028, canon, GUI, new physics, population, renewal or planner.

## Question and hypotheses

Can retained personal extraction outcomes alter subsequent voluntary valuation
of already eligible preparation, and what executed individual consequences follow?
Test H1 failure, H2 success, H4 selected activity, H5 material/social consequences,
H6 mixed benefit/harm, H7 stale success, H8 forgetting, H9 score-only and H10
reconvergence. H3 specific personal-use learning is unidentifiable with fungible
food and is explicitly not implemented. Null/insufficient opportunities, worsened
outcomes and lost opportunities are valid results. More output is not welfare.

## Gate B: exact mechanism, frozen before treatment

Fixed arm: exact026 C1 ProjectedNeed, no new cognitive cells or score adjustment.
Experience arm: same C1 plus the following new, separately costed opt-in memory.
Each actor holds at most TWO outcome cells in live delivery order. A cell has
`owner:u32, received:u64, success:bool` only. No source stock, content, event
archive, cumulative counts or hidden aggregate survives eviction. This single-
source study estimates recent own extraction success, not per-source generality.
Initial cells empty. Each live Taken/Insufficient delivery projects one cell.
Before insertion and each decision, discard cells with received+24 <= now.
If two remain, remove oldest; append new. No refresh on access. Boundary tick24
is exclusive. Expiry is also applied at terminal export. Observer audits retain
before/after/evictions but never feed cognition. Own other cognitive caps unchanged.

For n retained cells, s successes: expected=50 if n=0, else floor(100*s/n).
Adjustment=trunc_toward_zero((expected-50)/5), in[-10,10]. Exact small integers,
no overflow at cap2; no exponential hidden state. This means recent frequency
relative to neutral50, not a calibrated prediction under changing depletion.
The symmetric10-point range is an arbitrary conservative heuristic, NOT tuned
against treatment or chosen to ensure divergence. Success need not be useful;
failure need not recur. New success/failure evidence can mislead.

Eligible Prepare only:
fixed=min(100,H+5*floor(D/4))-D;
learned=fixed+adjustment. Base score increases by adjustment too; no new cap.
Ineligible remains-1; other four terms/masks/effort/order unchanged. Strict first
maximum in Wait,Consume,Invite,Acquire,Prepare order; no bonus may make an
ineligible candidate win. Pure update/scorer replaceable, bounded input only.
No new action/admission/consent/response/timing/resource privilege.

package/target prevents026 I1 collision. Fixed mode must exactly reproduce all50
original ProjectedNeed histories; also verify both inherited modes100 before
treatment. Commit/push registration before execution; bind runtime/readers before
full treatment. Native deterministic replay all100; independent reader rebuilds
receipt ownership/timing, retention/arithmetic, scores/ties, physics, needs,

Scratch controls: private/future/missing receipt, observer stock field, forgotten

attribution, duplicate output, waste/replenishment, matrix/source substitution.

isolated Rust checks and archive guard. Preserve failures; invalid design requires

Falsify behavioral effect if only scores/memory differ, fixtures mismatch,
history recovers cognition, actor sees future/partner-private/observer stock, or
execution is only a probe. Stop on insufficient legitimate opportunity; no fake
feedback. Scientific acceptance requires all registered rows including null/harm,
independent reconstruction, exact replay and source/publication integrity.
