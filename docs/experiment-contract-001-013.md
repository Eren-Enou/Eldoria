## Accepted capability and limits

An individual can revisit a previously discounted opportunity using only locally
available state, discover a provider's later legitimate acquisition through an
actual selected reply, revise assessment/expectations and change later executed
resource history. The consequence can persist through consumption. This tested
extension adds no persistent cognitive collection; it reuses the existing architecture.

Preserve three separate decisions: scientific acceptance; preservation of optional
research policies; default adoption. Only the first two are justified. No universal
policy superiority, robust period-four timing, acceptable general exploration cost,
truthful change, hidden-change detection, minimal architecture or natural social
environment is established. No 014 work is authorized by this contract.
