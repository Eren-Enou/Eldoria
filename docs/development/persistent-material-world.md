## Explicit headless interface

Build in the repository root (a normal developer Cargo toolchain is required):

```powershell
cargo build --release --locked --manifest-path prototypes/persistent-material-world/Cargo.toml --target-dir prototypes/persistent-world/target -j 1
$material = (Resolve-Path prototypes/persistent-world/target/release/woi-persistent-material-world.exe).Path
$work = Join-Path (Resolve-Path target).Path 'material-example'
New-Item -ItemType Directory $work
& $material config 1 (Join-Path $work 'config.json')
& $material create (Join-Path $work 'world-example') (Join-Path $work 'config.json')
& $material advance (Join-Path $work 'world-example') 3
& $material status (Join-Path $work 'world-example')
& $material events (Join-Path $work 'world-example') 0
& $material verify (Join-Path $work 'world-example') --generation 2
& $material advance (Join-Path $work 'world-example') 2048 --codec zlib
& $material check (Join-Path $work 'world-example')
& $material storage (Join-Path $work 'world-example')
& $material finalize (Join-Path $work 'world-example')
```

`create` makes its first immutable save. `advance` executes bounded real scheduler
steps and saves; each invocation opens in a new process. `save` publishes a dirty
state only, and an unchanged save is a no-op. `state` exports the actual complete
checkpoint to a new observer file. `baseline` records uninterrupted state hashes
and verifies original corrected025 history; `reference` compares the final Trial
with that producer. These audits never provide policy inputs.

To deliberately preserve an unsaved completed suffix, use `interrupt DIR STEPS`.
Normal open will refuse the unmatched tail. Create a fresh external branch root
and explicitly select a verified generation:

```powershell
& $material recover SOURCE NEW-BRANCH-ROOT/world-example --generation 2
```

The basename must retain the original world ID. Recovery preserves both excluded
verified committed bytes and remaining unverified tail bytes with separate hashes,
without changing the parent or replaying either suffix into cognition. The branch
continues from its selected clock, absolute deadlines, escrow, stock and memories.
This is process-interruption recovery, not demonstrated power-loss durability.

The separate crate avoids changing the existing reader's runtime identity or the
workbench's GUI/session dispatch. It compiles the canonical transport implementation
with explicit material projections, rather than maintaining another commit/recovery
algorithm. Original025 sources remain the sole authority for policy and physics.
