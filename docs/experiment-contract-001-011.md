## Different outcomes of an inquiry

Keep these distinct; one does not imply all the others:

| Outcome | Protected interpretation |
|---|---|
| A response is received | It can be silent, uninformative, redundant or a legitimate new receipt |
| Novelty is recorded | Existing 006 signature novelty, not calibrated expected Grouped progress |
| Retained Grouped support changes | Separate received-origin/quality aggregation with claim fallback semantics |
| Concern status changes | Existing local threshold/status rules; resolution can be mistaken |
| Source/method expectation changes | Selected valid replies train the existing bounded cell, even without support change |
| Later inquiry behavior changes | A subsequent local choice; not automatically useful or materially consequential |
| Material consequence executes | Actual legal resource action/accounting/history, with persistence separately checked |

A response does not guarantee support change; positive novelty does not guarantee
concern progress. No-change questions can update expectations, attempts/failures and
receipt metadata. Such learning is not automatically beneficial; 011 does not
establish its longer-term value. Do not require every inquiry to produce immediate
progress or redefine the old learning mechanism to match the outcome metric.

Controlled StatusValue asks32 times,29 Direct, with3 support/status changes and29
no-change questions. Held-out asks144,129 Direct, with4 changes and140 no-change
questions. Every selected StatusValue question in these traces changes a learned
expectation. “Unproductive” is the review's narrow immediate support/status measure,
not absence of all cognition. Preserve the entire reviewed count and comparison tables.
